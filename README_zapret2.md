# ZAPRET2 (Fork ИИ)

Улучшенная версия утилиты для авто-подбора индивидуальных стратегий обхода DPI для каждого домена.

## Авторы
- **Оригинал:** bol-van  
- **Официальный репозиторий:** https://github.com/bol-van/zapret  
- **Fork:** сделан ИИ

---

## Возможности

✅ **Авто-подбор стратегий** — каждый домен получает свою рабочую конфигурацию  
✅ **Двухфазный режим** — быстрая проверка + глубокий анализ для проблемных доменов  
✅ **Простое TUI меню** — управление через текстовый интерфейс  
✅ **Сохранение результатов** — стратегии сохраняются в файл для использования в zapret

---

## Структура файлов

```
/workspace/
├── zapret2.sh              # Главный скрипт (мульти-скрипт с TUI)
├── config                  # Основной файл настроек (создается автоматически)
├── domain_strategies.conf  # Индивидуальные стратегии доменов (обновляется скриптом)
├── blockcheck2.sh          # Утилита проверки (должна быть в той же папке)
└── README.md               # Этот файл
```

---

## Конфигурационные файлы

### 1. `config` — основной конфиг zapret2

**Где находится:** `/workspace/config`  
**Что содержит:**
- Список доменов для проверки
- Параметры firewall и ipset
- Настройки nfqws2 (интерфейс, порт)
- Дополнительные опции

**Пример содержимого:**
```bash
# Список доменов для проверки (через пробел)
DOMAINS="rutracker.org youtube.com instagram.com"

# Режим работы (auto/manual)
MODE="auto"

# Пакетный режим (1/0)
BATCH_MODE=1

# Интерфейс для nfqws
IFACE="br-lan"

# Порт для перехвата
PORT="80,443"
```

⚠️ **Важно:** Этот файл создается автоматически при первом запуске и может быть отредактирован через меню (пункт 2).

---

### 2. `domain_strategies.conf` — файл индивидуальных стратегий

**Где находится:** `/workspace/domain_strategies.conf`  
**Что содержит:** Найденные рабочие стратегии для каждого домена  
**Формат:** `домен|протокол|стратегия`

**Пример содержимого:**
```
rutracker.org|http|--lua-desync=http_hostcase
youtube.com|https|--lua-desync=fake:tcp_md5
netflix.com|https|--dpi-desync=fake
```

🔄 **Важно:** Этот файл **автоматически обновляется** скриптом `zapret2.sh` при каждом запуске авто-подбора (пункт 1 меню).

---

## Где хранятся стратегии?

Стратегии хранятся в файле **`domain_strategies.conf`** в корне проекта (`/workspace/`).

После успешного подбора стратегий вы можете использовать этот файл для настройки zapret:
```bash
# Пример применения стратегий из файла
while IFS='|' read -r domain proto strategy; do
    echo "Домен: $domain, Стратегия: $strategy"
    # Добавьте логику применения стратегии к вашему конфигуратору zapret
done < /workspace/domain_strategies.conf
```

## Использование

### Запуск TUI меню

```bash
chmod +x zapret2.sh
./zapret2.sh
```

### Меню предлагает 4 опции:

1. **Запустить авто-подбор стратегий**  
   Проверит все домены из конфига, для неработающих подберет индивидуальную стратегию.

2. **Редактировать конфиг (config)**  
   Откроет файл `config` в редакторе (nano или $EDITOR).

3. **Показать текущие стратегии**  
   Выведет содержимое файла `domain_strategies.conf`.

4. **Выход**

---

## Как это работает?

1. Скрипт читает список доменов из файла `config`
2. Для каждого домена запускается проверка (через `blockcheck2.sh`)
3. Если домен работает с базовой стратегией — помечается как "рабочий"
4. Если не работает — запускается перебор вариантов пока не будет найден рабочий
5. Результаты сохраняются в `domain_strategies.conf`

**Результат:**  
- 20 доменов могут работать на базовой стратегии
- 5 доменов (например, YouTube) получат индивидуальные стратегии
